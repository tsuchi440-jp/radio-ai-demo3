介助動作フィジカル評価・教育フィードバック基盤
総合要求仕様書（Version 2.0）

１．プロジェクトの目的と全体アーキテクチャ

本システムは，介護・医療現場における移乗介助動作を定量的に評価し，腰痛予防および技能向上のためのフィードバックを自動化する統合プラットフォームである．
システムは，現場で操作する「フロントエンド（UI/UX層）」と，AI推論・力学計算を担う「バックエンド（解析層）」に分割され，各モジュールの評価基準や計算式は，プログラムの根幹を直接改変せずに外部ファイルから容易にカスタマイズ（疎結合化）できる設計とする．

２．モジュール別 要求要件

【要件1】フロントエンドUI：動画対比と動的チェックリスト

現場の指導者が直感的に操作できるWebベースのUIを構築する．

  • 動画の同期再生：お手本動画（固定）と，現場で撮影した被験者の動画（ファイル選択）を並べて同時再生できる機能．
  • 外部定義型・5段階チェックリスト機能：画面上に5段階評価（1:全くできていない ～ 5:完璧である）のチェックリストを配置する．
    [重要] チェック項目（設問テキスト）はHTMLソースコードに直接記述せず，外部ファイル（checklist_config.csv 等）から動的に読み込んで生成すること．これにより将来の評価指標の変更にノーコードで対応可能とする．
  • PDFエクスポート機能：評価完了後，「評価結果を保存」ボタンを押下することで，チェック結果および解析結果をPDF形式でダウンロードできること．保存時にダイアログを表示し，指導者が任意のファイル名（例：20260605_山田太郎_移乗評価.pdf）を指定して保存できる仕様とすること（jsPDFやhtml2pdf.jsなどのライブラリ活用を推奨）．

【要件2】バックエンドAI解析：YOLO骨格抽出とキネマティクス計測

撮影した動画から「解析ボタン」をトリガーとして，Pythonによる重計算（ローカル実行）を起動する．

  • 骨格オーバーレイ動画の生成（FPS厳守）：Ultralytics YOLOv8 または YOLO11-Pose（フルサイズモデル推奨）を用い，骨格を重畳した新しい動画ファイルを生成する．
    [重要] 書き出す動画のFPS（フレームレート）と解像度は，必ず元の入力動画と完全に一致させること（音声ズレや再生速度の異常を防ぐため，cv2.VideoCaptureで取得した元FPS値をcv2.VideoWriterに正確に引き継ぐこと）．
  • キネマティクスデータの抽出と出力：
    • 上体前屈角（腰部屈曲角）：直立姿勢を「0度」とし，前屈（お辞儀）方向をプラスとする．肩の中点と腰の中点を結ぶ体幹ベクトルと，鉛直線のなす角から算出すること．
    • 膝角度：腰・膝・足首の3点の座標から成す内角を計算すること．
    • 捻り動作（代償回旋）の秒数：動画初期の直立時の「肩幅（ピクセル幅）」を基準とし，肩幅が基準の65%未満に縮小したフレームを「捻りが発生している」と判定し，その合計フレーム数÷FPSから「捻り秒数」を算出すること．
  • 統計グラフの出力：抽出した全フレームの時系列データから，「上体前屈角のヒストグラム（分布）」および「膝角度のヒストグラム」を画像（PNG等）として出力すること．加えて，「上体前屈角の最大値・最小値」を数値として算出すること．

【要件3】バイオメカニクス計算：腰部負担値の算出と外部化

抽出した上体前屈角等のデータをもとに，椎間板や脊柱起立筋にかかる「腰部負担値」を算出する．

  • 計算式の外部ファイル化（プラグイン構造）：力学計算式（モーメントアーム等のパラメータ）は，メインのPythonコード内にハードコードしてはならない．
    [重要] 計算式や定数パラメータは，別ファイル（例：formula_config.py や physics_params.json）として切り出すこと．これにより，将来的に研究代表者が新しい推定モデルを考案した際，システム本体を改修することなく数式のみを差し替えられる構造を担保すること．

【要件4】自動フィードバック：ロジックベースのアドバイス提示

計算された「腰部負担値」「最大前屈角」「捻り秒数」の数値を条件分岐させ，介助者へのテキストアドバイスを自動生成する．

  • 判定ロジックとテキストの外部ファイル化：アドバイスの内容や，それを発火させるための「しきい値（Threshold）」は別ファイル（例：advice_rules.csv または advice_config.json）で管理すること．
  • 外部ファイルの構成例：
    • ルール1: if 捻り秒数 > 2.0 ⇒ メッセージ: 「体幹の回旋（ひねり）が2秒以上続いています．椎間板ヘルニアのリスクが極めて高いため，足の向きを変えて対応してください．」
    • ルール2: if 腰部負担値 > 300 ⇒ メッセージ: 「腰部への内的負荷が基準値を超過しています．対象者にもっと密着してください．」
  • 解析完了後，このルールエンジンを通過させて生成されたテキスト群を，UI画面および出力PDFに反映させること．

３．開発担当者へのマイルストーン（推奨手順）

本システムの要件は多岐にわたるため，以下のフェーズに分けてアジャイル的に開発を進めること．

  • Phase 1（UIとAIの基礎）：HTML/JSで動画の同時再生と，任意のCSVから読み込んだチェックリスト（5段階）の表示・PDF保存機能を作る．並行して，Pythonで動画を読み込み，YOLOで骨格を重畳した同FPSの動画を書き出すスクリプトを完成させる．
  • Phase 2（キネマティクスとグラフ化）：Pythonスクリプトを拡張し，上体前屈角（最大・最小），膝角度，捻り秒数を計算し，Matplotlib等でヒストグラム画像を出力させる．
  • Phase 3（アーキテクチャの疎結合化：最重要）：「腰部負担値の計算関数」と「アドバイス判定ロジック」を別の設定ファイル（JSON等）に切り離し，メインのPythonプログラムがそれを動的に読み込んで結果を出力する「ルールエンジン」の構造を完成させる．
